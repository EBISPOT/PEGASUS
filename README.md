# 🧬 PEGASUS Framework Documentation
![version](https://img.shields.io/badge/version-0.0.2.0-blue)

This repository hosts the documentation for **PEGASUS** — the Predicted Effector Gene Annotation and Standardization framework.

PEGASUS provides a structured approach for reporting and sharing **Predicted Effector Gene (PEG)** information through a **reusable evidence matrix** and a **ready-to-use PEG list** that summarizes integrated conclusions across evidence streams.

The framework is being co-developed through a collaborative effort between the **European Bioinformatics Institute (EMBL-EBI)** and the **Broad Institute of MIT and Harvard**, together with contributions from our wider PEG working group members.

# 🔢 Versioning

PEGASUS follows a four-part version number: **`A.B.C.D`**

| Position | Example | Meaning |
|---|---|---|
| **A** — first | `1`.0.0.0 | Schema structure change — a fundamental reorganisation of the schema |
| **B** — second | 0.`1`.0.0 | Major schema improvement — a significant change to existing schema fields |
| **C** — third | 0.0.`1`.0 | Schema details improvement — minor corrections or additions to schema fields |
| **D** — fourth | 0.0.0.`1` | Documentation improvement — wording, examples, or formatting only |

> Trailing zeros are omitted in displayed version numbers. For example, `0.0.2.0` is shown as `0.0.2`.
